# Option Pricing System in C++

This project implements a simple option pricing system in **C++** using
object-oriented programming principles. It supports pricing **European
call and put options** using:

- **Black–Scholes closed-form model**
- **Monte Carlo simulation**

## Features
- Object-oriented design with inheritance and polymorphism
- Modular pricing models
- User-driven input for option parameters
- Support for both call and put options
